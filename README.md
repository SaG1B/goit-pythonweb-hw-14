# PhotoShare REST API

REST API для обміну фотографіями, створений на FastAPI, SQLAlchemy та PostgreSQL.

## 🚀 Основний функціонал
- **Auth**: Реєстрація, авторизація (JWT), вихід та розмежування ролей.
- **Users**: Управління профілем, перегляд публічних даних, бан користувачів (Admin).
- **Photos**: Завантаження, пошук та перегляд світлин.
- **Comments & Ratings**: Коментування та оцінка фотографій.
